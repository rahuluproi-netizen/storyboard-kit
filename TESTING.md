# Repeatable checks

Open index.html locally.

- Build from the sample inputs and confirm output is complete.
- Copy (if the browser allows it) and download; verify the downloaded text.
- Enter `<img src=x>` as text; it should display as plain text, not markup.
- At 390px and 1280px width, confirm controls and output do not overflow.
- Prompt Desk: switch each preset, save, edit, reload saved, then clear.
- Storyboard Kit: 31 seconds across six shots should give one 6s shot and five 5s shots. Thirteen shots must show a validation message.
- Clear required inputs; the form must not generate a new draft.

Automated browser checks were also run during preparation. The app itself has no dependencies.
